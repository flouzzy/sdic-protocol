## Summary of Changes
This PR introduces RFC-001, standardizing the Action Ledger data structure for multi-agent synchronization. It provides a strict deterministic protocol to ensure that autonomous agents can propose state changes safely within the SDIC-1 framework.

## Rationale & Architectural Impact
As multi-agent systems (Swarm Consensus) become more prevalent, the risk of concurrent state mutation and unstructured data injection by probabilistic agents increases. This RFC protects enterprise systems from such unpredictability by removing agents' self-regulation capabilities. Instead, it delegates validation to a deterministic host application that evaluates mathematically verifiable, cryptographically signed Action Ledger proposals against strict JSON Schemas.

## Proposed Specification Changes
- **Target Component:** Pilier 4: The Action Ledger (ecosystem/RFCs/RFC-001.md)
- **Modification:** Added a strict JSON Schema (`SwarmIntentProposal`) with `"additionalProperties": false` for state change proposals. Implemented cryptographic non-repudiation rules requiring canonicalized payload signatures to prevent replay and relabeling attacks in multi-agent environments.

## Backward Compatibility
This change is fully backward-compatible. It is a new addition to the SDIC-1 framework (v1.0.0-draft) that expands on the Action Ledger to support multi-agent synchronization without breaking existing single-agent implementations.
