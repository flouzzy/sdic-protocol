## Summary of Changes
This PR introduces SDIC-ERC-0011, which standardizes a deterministic, pre-execution sanitization layer for semantic intents. This effectively neutralizes prompt injection attacks that manage to produce structurally valid JSON by filtering them at the runtime level.

## Rationale & Architectural Impact
Relying on probabilistic LLMs to self-detect prompt injections is mathematically flawed, as advanced injections bypass cognitive filters. By introducing a deterministic runtime rule engine that validates the output intent against strict business invariants, we ensure that malicious payloads are dropped before execution. This robustly protects enterprise systems from unpredictable AI behavior by shifting the defense from the probabilistic generation layer to the deterministic execution layer.

## Proposed Specification Changes
- **Target Component:** Pilier I: Isolation Cognitive / Deterministic Control Layer
- **Modification:** Added a mandatory "Sanitization" phase where the deterministic host evaluates structurally valid intents against hard-coded business rules (e.g., `amount <= user_balance`) before cryptographic signing and Action Ledger propagation.

## Backward Compatibility
This change is fully backward-compatible with v1.0.0-draft implementations. The deterministic sanitization phase is introduced as an optional but highly recommended step between the existing Schema Validation and Action Ledger propagation layers.
