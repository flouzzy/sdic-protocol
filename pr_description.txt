## Summary of Changes
This Pull Request standardizes the "Action Ledger" data structure for multi-agent synchronization to address the architectural gap of multi-LLM orchestration vulnerabilities. It introduces a strict JSON Schema representation (`AgentIntentProposal`) ensuring deterministic and auditable payload shapes when multiple autonomous agents update shared state.

## Rationale & Architectural Impact
As enterprise systems transition towards Swarm Consensus and multi-agent coordination, relying on a unified, sequential, and strict ledger is essential to prevent state corruption. This upgrade protects enterprise systems from AI unpredictability by enforcing zero-trust schema validation (`additionalProperties: false`) and cryptographic non-repudiation on every intent proposal, ensuring only compliant and mathematically verified state transitions reach the execution layer.

## Proposed Specification Changes
- **Target Component:** Pilier IV: The Action Ledger (Temporal Auditability) / Pilier II: Semantic Determinism
- **Modification:** Added `ecosystem/RFCs/SDIC-ERC-1.md` (and French translation) which enforces a standardized `AgentIntentProposal` JSON Schema with strict `additionalProperties: false` rules for the `payload` and root objects. It also mandates that cryptographic signatures in multi-agent proposals exclude the signature field itself when calculating the canonical representation.

## Backward Compatibility
This change represents a new standard extension for multi-agent use cases and is fully backward-compatible with v1.0.0-draft implementations of single-agent host applications.
