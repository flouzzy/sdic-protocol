## Summary of Changes
This pull request introduces ERC-101 to standardize the Action Ledger schema for multi-agent synchronization and Swarm Consensus. It establishes a strict, cryptographically secured JSON Schema that autonomous agents must use to propose state transitions, preventing non-deterministic routing vulnerabilities in parallel execution environments.

## Rationale & Architectural Impact
As systems scale to utilize multiple parallel agents (Swarm Consensus), the risk of state degradation and chained prompt injection multiplies. By enforcing a standardized, language-agnostic intent ledger strictly governed by a JSON Schema with `"additionalProperties": false`, this change mathematically isolates the host's deterministic execution engine from the unpredictability of multi-agent interactions, ensuring state integrity is preserved.

## Proposed Specification Changes
- **Target Component:** Pilier IV: The Action Ledger
- **Modification:** Added a standardized `SwarmConsensusIntent` JSON schema requiring cryptographic signatures, shared session IDs, and explicit payload definitions to regulate Swarm Consensus multi-agent orchestration.

## Backward Compatibility
This change is fully backward-compatible with SDIC-1 v1.0.0-draft implementations. It operates as an extension for multi-agent capabilities without disrupting the core requirements defined for single-agent systems.
