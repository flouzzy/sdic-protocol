## Summary of Changes

This Pull Request introduces **SDIC-ERC-0013** (in both English and French: `SDIC-ERC-0013.md` and `SDIC-ERC-0013.fr.md`), defining an external auditability framework and quantified safety guarantee standard for autonomous agents and reinforcement learning (RL) policies operating within critical safety domains (e.g., medical dosage administration, robotic actuation).

Key additions include:
- A mathematical framework for quantified safety guarantees enforcing failure probability upper bounds ($P(\text{Violation}) \le \epsilon$).
- Domain-specific JSON Schemas for medical action intents and robotic actuation proposals with strict `"additionalProperties": false` constraints.
- A verifiable external audit certificate schema (`VerifiableAuditCertificate`) enabling third-party cryptographically verifiable compliance checking.
- Canonical JSON representation (RFC 8785) hashing and Ed25519 signature verification instructions to prevent replay and relabeling attacks.
- Bilingual documentation in English and French with mutual cross-navigation links.

## Rationale & Architectural Impact

As autonomous AI agents and reinforcement learning policies transition into high-consequence domains such as healthcare and physical robotics, probabilistic model outputs pose unacceptable liability and physical safety risks. Traditional black-box testing cannot guarantee boundary compliance when policies adapt dynamically to infinite state spaces.

SDIC-ERC-0013 extends Pilier 2 (Semantic Determinism) and Pilier 4 (Action Ledger) of the SDIC Protocol by enforcing deterministic runtime safety barriers and cryptographically verifiable audit trails. Third-party auditors can evaluate execution safety without access to proprietary model weights, resolving the certification bottleneck for critical autonomous systems.

## Backward Compatibility

SDIC-ERC-0013 is fully backward-compatible with SDIC-1 and existing SDIC-ERC specifications. It introduces optional domain-specific schema extensions and audit certificate representations that do not modify core SDIC-1 ledger persistence or state transition mechanics.
