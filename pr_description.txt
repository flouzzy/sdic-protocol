## Summary of Changes
This PR introduces SDIC-RFC-001, standardizing the Action Ledger data structure to ensure deterministic multi-agent synchronization. It implements a strict JSON schema for intent proposals and a cryptographic signing requirement for state transition requests.

## Rationale & Architectural Impact
In multi-agent environments, allowing agents to independently propose unstructured state changes introduces race conditions and probabilistic outcomes. By forcing all agents to submit canonical, cryptographically signed, schema-validated intents to an append-only Action Ledger, the deterministic host system maintains absolute sequential authority over state transitions, completely isolating the persistence layer from the probabilistic agents.

## Proposed Specification Changes
- **Target Component:** Pilier I: Isolation Cognitive / Action Ledger
- **Modification:** Added a strict JSON schema (with `"additionalProperties": false`) defining `ActionLedgerEntry`, requiring `transaction_id`, `timestamp`, `agent_id`, an `intent_proposal` object, and a `cryptographic_signature`. Established a multi-agent synchronization algorithm where the deterministic host sequentially validates signatures and schemas before committing state.

## Backward Compatibility
This change is fully backward-compatible with v1.0.0-draft implementations. A single-agent system functions equivalently as a multi-agent system with a single participant writing to the Action Ledger.
