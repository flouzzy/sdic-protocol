## Summary of Changes
This pull request introduces SDIC-ERC-0012, which standardizes the Action Ledger data structure for asynchronous multi-agent synchronization. It provides a strict, deterministic, and cryptographically verified JSON schema to ensure safe state propagation across a multi-agent Swarm Consensus.

## Rationale & Architectural Impact
As enterprise AI environments evolve to support multiple autonomous agents, unstructured agent-to-agent communication creates severe risks of state drift, prompt injection propagation, and relabeling attacks. By standardizing the Action Ledger as the only deterministic conduit for agent orchestration, this RFC protects the enterprise system from AI unpredictability. It ensures that agents cannot directly mutate shared state, forcing them instead to submit strictly validated, mathematically signed intent proposals to the host system.

## Proposed Specification Changes
- **Target Component:** Pilier IV: Action Ledger / Swarm Consensus
- **Modification:** Introduces the `MultiAgentSyncIntent` JSON Schema that strictly enforces `"additionalProperties": false` to instantly neutralize prompt injection payloads. It also mandates cryptographic signature validation over a canonicalized payload string to ensure non-repudiation and prevent man-in-the-middle relabeling attacks during agent orchestration.

## Backward Compatibility
This change is fully backward-compatible with SDIC-1 v1.0.0-draft implementations. It functions as an extension to the existing Action Ledger concept without breaking single-agent setups, as they can safely ignore `correlation_id` and swarm coordination intent actions.
